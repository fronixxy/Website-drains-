# Website-drains-
Website: basement waterproofing and drains — price guide for Toronto & GTA.

Static site, no build step. Open `index.html` in a browser, or host the folder on GitHub Pages / Netlify.

- `index.html` — hero with quote form, services, price guide (interior / exterior / drains), cost estimator, process, city rebates, service areas, FAQ
- `styles.css`, `script.js` — styling and interactivity

Before publishing, replace the placeholders: company name "DryBase GTA", phone `(416) 000-0000`, `info@example.com`,
and confirm the business claims (warranty length, licensing/WSIB) match your company.
The quote form only shows a confirmation message; connect it to a service (e.g. Formspree) to receive requests.
