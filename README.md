# Website-drains-
Website: waterproofing and drains — approximate prices for Toronto & GTA.

Static site, no build step. Open `index.html` in a browser, or host the folder on GitHub Pages / Netlify.

- `index.html` — price list (interior / exterior / drains), cost estimator, work gallery, FAQ, contact form
- `styles.css`, `script.js` — styling and interactivity
- `images/work/` — illustrations of typical jobs. Replace them with real job photos (keep the same file names, or update the `src` in `index.html`).

Before publishing, replace the company name "DryBase GTA", phone `(416) 000-0000` and `info@example.com` with real contacts.
The contact form currently only shows a thank-you message; connect it to a service (e.g. Formspree) to receive requests.
